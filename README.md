# QuantTrader AI

A quantitative research and AI-assisted market intelligence platform for NIFTY 50 paper trading. Combines deterministic technical analysis with DeepSeek V3 to generate trade signals, portfolio intelligence, risk analytics, and daily market briefs — with zero real orders placed.

---

## Core Principle

**AI never decides what to buy or sell.**

All trading signals are generated by a deterministic quantitative engine (RSI, MACD, VWAP, EMA, ATR, Volume). DeepSeek V3 is used exclusively to explain signals, summarise market conditions, and generate portfolio intelligence reports.

---

## Features

### NIFTY 50 Market Scanner
- Scans all 50 stocks in parallel on demand
- Ranks by signal score, momentum, and volume spikes
- Tabs: Top Buy · Top Sell · Momentum · Volume Movers · All Signals

### Quantitative Signal Engine
Each stock is scored 0–100 using weighted technical indicators:

| Points | Condition |
|--------|-----------|
| +20 | Price above VWAP |
| +20 | MACD bullish crossover |
| +20 | RSI between 50–70 |
| +20 | Positive news sentiment |
| +20 | Volume spike > 20% above average |
| −10 | RSI overbought (> 75) or oversold (< 30) |
| −10 | Price below EMA 50 |

Signal thresholds: **80–100** Strong Buy · **60–79** Buy · **40–59** Hold · **20–39** Sell · **0–19** Strong Sell

### AI Trade Analyst (DeepSeek V3)
After a signal is computed, DeepSeek explains:
- Recommendation summary
- Confidence commentary
- Trade rationale
- Risk assessment

### Trade Recommendation Cards
Each card shows: signal, score, confidence, entry price, ATR-based target, ATR-based stop-loss, risk/reward ratio, and AI explanation.

### Portfolio Intelligence
- Portfolio Health Score (0–100)
- Diversification Score
- Sector Concentration breakdown
- Cash Utilization
- AI analysis: Strengths · Weaknesses · Recommendations

### Strategy Backtester
Test four rule-based strategies against historical NIFTY 50 data:

| Strategy | Rule |
|----------|------|
| Momentum | RSI > 55 + Price > EMA 50 |
| EMA Crossover | EMA 20 crosses EMA 50 |
| RSI Reversal | Oversold bounce (RSI < 35) |
| Sentiment + Volume | EMA trend + volume spike proxy |

Metrics returned: Total Return · CAGR · Sharpe Ratio · Sortino Ratio · Max Drawdown · Win Rate · Alpha vs NIFTY

### Risk Analytics
Per-stock and portfolio-level:
- Annualised Volatility
- Sharpe Ratio
- Sortino Ratio
- Maximum Drawdown
- Beta vs NIFTY 50
- Composite Risk Score (0–100)

### AI Market Brief
Daily market intelligence report generated by DeepSeek V3:
- Market Summary
- Market Mood (Bullish / Neutral / Bearish)
- Key Events
- Opportunities
- Risks
- Sectors in Focus

### Paper Trading
- ₹1,00,000 virtual starting balance
- BUY / SELL paper orders on any NIFTY 50 stock
- Real-time P&L, allocation tracking, trade history

## Quick Start

### Option 1 — One command (recommended)

```powershell
cd C:\path\to\quantrading_ai
.\run.ps1
```

This creates the Python virtual environment, installs all dependencies, and starts both servers.

### Option 2 — Two terminals

**Terminal 1 — Backend:**
```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
python app.py
```

**Terminal 2 — Frontend:**
```powershell
cd frontend
npm install
npm run dev
```

Open **http://localhost:5173**

> If PowerShell blocks script execution, run this once:
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```

## Environment Variables

Create `backend/.env` (copy from `.env.example`):

```env
NEWSAPI_KEY=
OPENROUTER_API_KEY=
OPENROUTER_MODEL=deepseek/deepseek-chat
DATABASE_PATH=quanttrader.db
```

Both keys are optional. When not configured, the app runs fully on deterministic demo data — signals, sentiment, portfolio analysis, and market briefs all work without any API keys.

| Variable | Required | Purpose |
|----------|----------|---------|
| `NEWSAPI_KEY` | No | Fetches real news headlines for sentiment analysis |
| `OPENROUTER_API_KEY` | No | Enables DeepSeek V3 AI explanations and reports |
| `OPENROUTER_MODEL` | No | Defaults to `deepseek/deepseek-chat` |
| `DATABASE_PATH` | No | SQLite file path, defaults to `quanttrader.db` |

## Important Notes

- No real money or real orders are involved at any point.
- AI (DeepSeek) explains signals — it does not generate them.
- All quantitative calculations are deterministic and reproducible.
- The backtester is for educational purposes. Past performance does not guarantee future results.
- `M&M` and `BAJAJ-AUTO` symbols are normalised to `MM` and `BAJAJAUTO` in URLs to avoid routing issues.
