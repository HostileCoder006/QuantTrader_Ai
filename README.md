# QuantTrader AI

A full-stack quantitative research and AI-assisted market intelligence platform for NIFTY 50 paper trading. Combines a deterministic technical analysis engine with DeepSeek V3.2 to generate trade signals, rank short-term opportunities, run strategy backtests, and analyse portfolio health — with zero real orders placed.

---

## Core Principle

**AI explains. Math decides.**

All trading signals, opportunity scores, and backtest results are generated by a deterministic quantitative engine (RSI, MACD, VWAP, EMA, ATR, Volume). DeepSeek V3.2 is used exclusively to explain signals, run investment committee analysis, and generate market intelligence reports.

## Pages & Features

### Dashboard
- Live NIFTY 50 index with daily change
- Portfolio KPI cards (value, cash, P&L, health score)
- Top Buy / Sell signal grid from the scanner
- AI-generated daily market brief (DeepSeek V3.2)

### Market
- Searchable live watchlist of all 50 NIFTY stocks
- Stock detail panel with trade ticket (BUY / SELL)
- News sentiment analysis with price-reaction history

### Scanner
- Full NIFTY 50 quant scan on demand
- Tabs: Top Buy · Top Sell · Momentum · Volume Movers · All Signals
- Market regime banner (BULLISH / BEARISH / NEUTRAL / HIGH_VOLATILITY / NO_TRADE)
- Click any stock → AI Analysis drawer with DeepSeek explanation + Pattern History tab

### Opportunities
Short-Term Opportunity Scanner with three integrated layers:

**1. Quant Scoring Engine**
- Scores all 50 stocks on 8 factors: momentum, MACD, RSI, volume, VWAP, trend, risk/reward, sector strength
- Horizon-specific factor weights: 1–5 Days · 1–2 Weeks · 2–4 Weeks · 1–3 Months
- Risk profile filters: Conservative · Balanced · Aggressive
- Composite Opportunity Score (0–100) with ATR-based entry / target / stop-loss

**2. Historical Similar-Environment Analysis**
- Searches up to 5 years of OHLCV history for setups similar to the current indicator fingerprint
- Returns: number of similar setups, win rate, avg/median return, best/worst outcome per horizon
- Strict no-lookahead bias — forward returns computed from past data only
- Results are historical evidence, not guaranteed predictions

**3. AI Investment Committee**
- 5 specialist analysts: Technical · Fundamental · Sentiment · Macro · Contrarian
- Each analyst returns: recommendation, confidence, thesis, evidence, risks, invalidation conditions
- Bull vs Bear debate for top-3 candidates (Deep mode)
- Final committee synthesis (weighted — not a simple vote count)
- Three cost-controlled modes: Quick (1 call) · Standard (~6 calls) · Deep (~19 calls)
- All results cached per scan — no duplicate API calls

### Portfolio
- Holdings table with live P&L and sector allocation
- Portfolio Health Score — shows "No holdings" when empty
- Sector concentration bar chart
- Diversification score, cash utilization, max single position
- AI portfolio analysis (strengths / weaknesses / recommendations)
- Portfolio risk metrics (Volatility, Sharpe, Sortino, Max Drawdown, Beta)

### Analytics
- Portfolio growth curve replayed from transaction history
- Best / worst trade highlights
- Per-stock risk inspector
- Full transaction history table

### Backtester
Tests four preset rule-based strategies against historical NIFTY 50 data:

| Strategy | Rule |
|----------|------|
| Momentum | RSI > 55 + Price > EMA50 |
| EMA Crossover | EMA20 crosses EMA50 |
| RSI Reversal | Oversold bounce (RSI < 35) |
| Sentiment + Volume | EMA trend + volume spike |

Metrics: Total Return · Alpha · CAGR · Sharpe · Sortino · Max Drawdown · Win Rate

### Strategy Lab
Custom configurable backtester:
- 8 entry/exit rules: RSI threshold, EMA crossover, MACD histogram, Price vs EMA50%, Volume spike
- Position sizing, stop-loss %, take-profit %, max holding days
- Brokerage costs and slippage (default 0.05% each way)
- Price chart with RSI panel and MACD panel (toggleable, adjustable params)
- BUY/SELL signal markers on the price chart
- Results: 12 metric cards + normalised equity curve + trade log
- Signals execute at next-bar open — no lookahead bias

### Journal
- Logs every recommendation with full indicator context and regime
- Auto-resolves 1D / 5D / 20D / 60D forward outcomes as time passes
- Tracks win rate, avg return, alpha vs NIFTY, and drawdown by horizon
- Performance breakdown by signal type

## Market Regime Engine

Classifies NIFTY 50 into five states using EMA20/50/200, RSI, and annualised volatility:

| Regime | Score Adjustment | Condition |
|--------|-----------------|-----------|
| BULLISH | +10 | Price above all EMAs, RSI 50–75, normal vol |
| NEUTRAL | 0 | Mixed signals |
| BEARISH | −15 | EMA20 below EMA50, RSI < 40 |
| HIGH_VOLATILITY | −10 | Annualised vol > 25% |
| NO_TRADE | −25 | Extreme conditions |

Regime is applied as a score adjustment to every individual stock signal and cached for 5 minutes.

---

## Historical Pattern Search

For any NIFTY 50 stock, searches up to 10 years of OHLCV history for the 20 most similar historical setups using a 5-feature Euclidean distance fingerprint (RSI, MACD histogram, price vs VWAP%, price vs EMA50%, volume vs 20D avg%). Returns 5D / 20D / 60D forward return statistics with strict no-lookahead guardrails.

## Quick Start

### Option 1 — One command

```powershell
cd C:\path\to\quantrading_ai
.\run.ps1
```

Automatically creates the Python virtual environment, installs all dependencies, and starts both servers.

### Option 2 — Manual (two terminals)

**Terminal 1 — Backend:**
```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
python app.py
```

**Terminal 2 — Frontend:**
```powershell
cd frontend
npm install
npm run dev
```

Open **http://localhost:5173**

> If PowerShell blocks execution:
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```

## Environment Variables

Copy `backend/.env.example` to `backend/.env`:

```env
NEWSAPI_KEY=your_key_here
OPENROUTER_API_KEY=your_key_here
OPENROUTER_MODEL=deepseek/deepseek-v3.2
DATABASE_PATH=quanttrader.db
```

All keys are optional. The app runs fully on deterministic data without any API keys — every AI feature has a demo fallback.

| Variable | Required | Purpose |
|----------|----------|---------|
| `NEWSAPI_KEY` | No | Real news headlines for sentiment analysis |
| `OPENROUTER_API_KEY` | No | DeepSeek V3.2 AI explanations and committee analysis |
| `OPENROUTER_MODEL` | No | Defaults to `deepseek/deepseek-v3.2` |
| `DATABASE_PATH` | No | SQLite path, defaults to `quanttrader.db` |
